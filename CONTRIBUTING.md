# Участие в разработке

Основные функции должны работать на Python 3.9+ без сторонних библиотек и без токена в тестах. Реальный токен, личную переписку, сырые ответы с персональными данными и папку собственного архива в issue/PR не прикладывайте.

## Проверки

```sh
python3 -B -m unittest discover -s tests -v
python3 download.py --help
python3 view.py --help
```

Windows: замените `python3` на `py`. Серверные тесты открывают временный порт на `127.0.0.1`. API и CDN в тестах подменяются искусственными ответами.

## Границы модулей

- `api.py` отвечает за запросы и очистку секретов, `collector.py` — за обход API.
- `media.py` не получает токен API: он работает с возвращёнными адресами файлов.
- `store.py` хранит относительные пути, чтобы архив можно было переносить между ОС.
- `view.py`/`server.py` не запускают сбор и не запрашивают токен.
- Интерфейс — обычные `web/index.html`, `app.css`, `app.js`, без сборщика и внешних ресурсов.

Не считать превью или адрес проигрывателя сохранённым видео. Ошибки источников и недоступные типы сохранять в отчёте, а не выдавать за пустые разделы. Для изменения схемы или файловой раскладки явно менять версию формата и документировать совместимость.

При исправлении добавьте тест воспроизводимого поведения: пагинация/возобновление, имена путей Windows, перенос архива, несколько источников одного файла, безопасное отображение текста или локальное воспроизведение.
