# Безопасность и приватные данные

Токен используется только для запросов VK API и не записывается в базу, исходные ответы или отчёты. Загрузка медиа выполняется без передачи API-токена. По умолчанию ввод токена виден в собственной консоли; `--hidden-token` скрывает его.

Локальный просмотрщик слушает `127.0.0.1`, открывает базу только для чтения и обслуживает известные ресурсы. Документы выдаются как скачиваемые файлы. Текст сообщений не исполняется как HTML. Интерфейс не загружает внешние шрифты, скрипты или удалённые изображения автоматически.

Архив содержит личные сообщения и другие персональные данные. Не прикладывайте его к публичному отчёту об ошибке. Для воспроизведения достаточно синтетического примера, версии Python, ОС, названия метода и текста ошибки без токена и полного адреса авторизации.

Для сообщения об уязвимости используйте приватное сообщение об уязвимости GitHub, если владелец репозитория включил эту возможность. Если приватного канала нет, создайте issue с просьбой согласовать канал связи, не публикуя секреты и детали эксплуатации.
